Metric guide

Waiting time
Turnaround − Burst

Turnaround time
Completion − Arrival

Response time
First start − Arrival

Throughput
Completed processes ÷ total elapsed time

This is a deterministic educational simulation. No context-switch overhead, I/O blocking, or dynamic aging is modeled. CPU utilization and throughput are measured from time 0 (including any initial idle interval). Ties use earlier arrival then input order. For Round Robin, processes arriving at a quantum boundary join the queue before the unfinished process is requeued.
